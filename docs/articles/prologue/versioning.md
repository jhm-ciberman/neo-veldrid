# Versioning and Compatibility

NeoVeldrid follows [Semantic Versioning](https://semver.org). Within a major version, minor and patch releases preserve source compatibility and documented behavior.

Binary compatibility and serialization compatibility are not guaranteed. Undocumented behavior, including bugs, may change between releases.

## Named Arguments

Named arguments are not covered by NeoVeldrid's source compatibility guarantee. Parameter names may change between releases.
